## 🔌 איך לשלב Google Apps Script?

### לניוזלטר:
1. פתחי Google Sheets חדש
2. כלים → עורך סקריפט
3. העתיקי את הקוד שסיפקת (הפונקציה `sendNewsletter`)
4. פרסמי כ-Web App
5. העתיקי את ה-URL
6. הדביקי ב-[admin.html](admin.html) בפונקציה `sendNewsletter`

### לשליחת קבצים:
אותו תהליך, רק עם הפונקציות:
- `processAndSendFiles`
- `sendManualEmail`
- `getCustomersList`
- `getFilesList`

📖 **יש לך את כל הקוד ב-Google Apps Script שסיפקת!**
